# 黄金 EA preset(经过验证的配置)

这里放 GoldScalper EA 的 preset(`.set` 文件)。**监测器只会在这几个经过验证的配置之间
建议切换,不会凭最近几笔盈亏去乱调止损/盈亏比** —— 那样做在 edge 这么小的黄金上一定更差。

## 有哪些 preset

| 文件 | 是什么 | 什么时候用 |
|------|--------|-----------|
| `default_validated.set` | M15 · $3止损 · RR1:2 · 风险1% | 默认。样本外验证里唯一勉强为正的配置。 |
| `defensive.set` | 风险0.5% · 成本过滤更严 · $4止损 | 监测器报 `RETHINK` 时:edge 还没证明够大,用它亏得更慢、继续攒样本。 |

## 监测器的结论对应什么动作

`mt5_bridge.py` 每次跑完给一个结论,你(或以后自动地)照着做:

| 结论 | 含义 | 该做什么 |
|------|------|---------|
| `ACCUMULATE` | 样本 < 20 笔 | 什么都不动,让它继续跑 |
| `OK` | 置信下界站上 0,有正 edge | 保持 `default_validated`,继续 |
| `WATCH` | 分不清 edge 还是运气 | 保持当前 preset,**别动参数** |
| `RETHINK` | 样本已排除「edge 够大」 | 换 `defensive.set`,或考虑改入场逻辑 |
| `HALT` | 明显坏了 / 回撤爆表 | **卸下 EA**,回研究阶段,别调参续命 |

## 怎么在 MT5 里加载一个 preset

1. 图表上右键 EA(或 EA 属性)→ **输入(Inputs)** 标签
2. 右下角 **加载(Load)** → 选这里的 `.set` 文件 → 确定
3. EA 会用新参数重新初始化

> 注:这些 `.set` 是文本文件,可直接看/改。`InpTimeframe=15` 表示 M15;
> 布尔用 `true`/`false`。改完在 MT5 里重新加载即可。

## 想让它「自己换」(全自动)

现在 EA 的参数是 MT5 的 `input`,不读外部文件,所以默认是**提醒你手动换**。
要做到监测器判断后自动生效,需要给 EA 加一小段「开机/定时读 `preset.json`」的代码 ——
这是第二步,做法写在 `SETUP_MT5_MONITOR.md` 末尾。在那之前,手动加载 `.set` 最安全。

*研究/学习用途,不构成投资建议。黄金杠杆交易可能损失全部本金。*
