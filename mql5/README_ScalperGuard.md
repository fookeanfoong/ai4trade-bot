# XAUUSD ScalperGuard — 黄金短线自动交易机器人

MT5 智能交易系统（EA），按你给的风控规格硬编码。**默认只允许在 Demo 账户运行。**

文件：`XAUUSD_ScalperGuard.mq5`

---

## 一、先看这个：$200 + 20倍杠杆做黄金，数学上跑不动

这不是劝退，是开始跑之前必须先确认的经纪商参数。

黄金标准合约 = 100 盎司/手，最小手 0.01 = 1 盎司。

**保证金**（0.01 手，金价按 $4,000/盎司估算）：

| 杠杆 | 0.01 手占用保证金 | 占 $200 账户 |
|---|---|---|
| 1:20 | **$200** | **100% —— 开不了** |
| 1:100 | $40 | 20% |
| 1:200 | $20 | 10% |
| 1:500 | $8 | 4% |

EA 里有一道 `InpMaxMarginPctPerPos = 35%` 的闸门（禁止满仓）。**在 1:20 下，0.01 手黄金就要吃掉整个账户，EA 会一直 NO TRADE。** 这是规格里"绝对禁止满仓"的直接后果，不是 bug。

**止损空间**：1% 风险 = $2。0.01 手时每 $1 金价波动 = $1 盈亏，所以 $2 风险 ⇒ 止损最多只能放 $2.00/盎司。黄金 M5 的 ATR 常在 $1.5–$4，也就是说很多信号的结构止损会超过预算，EA 会拒单（这是对的——规格禁止为了下单而缩止损）。

**盈利目标**：+$50 / $200 = **单日 +25%**，按 1% 风险算需要 +25R。这个数字在规格里是"停止线"不是"任务"，EA 也是这么执行的（达到就停），但实际上几乎不会触及。

**所以开跑前先在 MT5 里确认三件事**（EA 启动时会自动打印这些数字到"智能交易系统"日志）：
1. 你的经纪商 XAUUSD 最小手数是 0.01 还是 0.001
2. 黄金品种的实际杠杆（很多经纪商对黄金单独设杠杆，不等于账户杠杆）
3. 平均点差（超过 $0.35 EA 会直接不做）

## 二、安装

1. 装 MetaTrader 5（从你经纪商官网下载），登录 **Demo 账户**。
2. MT5 菜单 → `文件` → `打开数据文件夹`。
3. 把 `XAUUSD_ScalperGuard.mq5` 复制到 `MQL5\Experts\`。
4. MT5 里按 `F4` 打开 MetaEditor → 左侧找到该文件 → 双击 → 按 `F7` 编译。应显示 `0 errors`。
5. 回到 MT5，打开 **XAUUSD 的 M5 图表**。
6. 工具栏点亮 `算法交易`（Algo Trading）按钮。
7. 从"导航器 → 智能交易系统"把 `XAUUSD_ScalperGuard` 拖到图表上。
8. 弹窗里勾选 `允许算法交易`，确认参数，点确定。

图表左上角会出现状态面板：当日盈亏、笔数、连亏、当前模式、点差、ATR、以及"为什么现在不做"。

日志文件：数据文件夹 → `MQL5\Files\XAUUSD_ScalperGuard_log.csv`，每一个决策（包括每一次 NO TRADE 的原因）都有记录。

## 三、规格 → 代码 对照

| 规格条款 | 实现位置 / 参数 |
|---|---|
| 二、+$50 停止交易 | `InpDailyProfitTarget=50`，达到即平仓 + 当天不再开仓 |
| 三、-$15 停止交易 | `InpDailyMaxLoss=15`，触及即**平掉持仓**并停止 |
| 四、单笔 1%（上限 2%） | `InpRiskPctDefault=1.0` / `InpRiskPctMax=2.0`；2% 只在满分 7/7 信号 + 无连亏 + 未进保守模式时启用 |
| 五、按止损距离反推手数 | `CalcLot()` — 风险金额 ÷（止损距离 × 每手每$1价值），只向下取整 |
| 六、绝对禁止满仓 | `InpMaxMarginPctPerPos=35%`，超限直接 NO TRADE |
| 七、17 项进场检查 | `BuildSignal()` + 各过滤器；信号冲突 → NO TRADE |
| 八/九、多空条件 | HTF趋势 + LTF趋势 + 市场结构 + 动量 + ADX + 突破回踩/回调确认，7 分制，默认需 ≥5 分 |
| 十、必须设止损 | 开仓即带 SL；检测到裸单先补设，补不上立刻平仓 |
| 十、禁止扩大止损 | `PositionModify` 只在新止损更靠盈利方向时执行 |
| 十一、TP1≈1R / TP2≈1.8R | `InpTP1_R` / `InpTP2_R`；TP2 会被前方最近关键位压缩 |
| 十二、盈利快速离场 | 1R 部分止盈 50% + 移保本 + ATR 追踪；动量衰竭/反向信号/逼近关键位/超时 → 提前平仓 |
| 十三、禁止亏损加仓、马丁 | 代码里没有任何加仓摊平路径；`InpAllowAddOn` 默认 false |
| 十四、加仓六项条件 | `AddOnAllowed()` — 已盈利≥0.5R、同向、独立止损、总风险≤2%、满分信号、当日非亏损，缺一不可 |
| 十五、每日≤10 笔 | `InpMaxTradesPerDay=10` |
| 十五、横盘/假突破/点差异常停手 | `MarketQualityOk()` + ADX + ATR 上下限 + 点差/ATR 比值 |
| 十六、连亏 2 → 观察模式 | 信号门槛 +1 分，风险降至 1% |
| 十六、连亏 3 → 当天停止 | `InpStopAfterConsecLoss=3` |
| 十七、+$20 保守 / +$30 收紧 | 门槛 +1 分、风险降至 0.75% / 门槛拉到满分 7、风险 0.5%、RR 要求 2.0 |
| 十八、重大新闻过滤 | MT5 经济日历，USD/EUR/XAU 高重要性事件，前 30 分钟 / 后 20 分钟禁开仓 |

**统计口径**：当日盈亏、笔数、连亏全部从**成交历史**实时推导（按 Magic Number 过滤），不依赖内存变量 —— EA 重启、MT5 重启、断线重连都不会把日内计数清零，绕不过去。

## 四、几个要自己确认的参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `InpAllowLiveAccount` | false | **保持 false**。真实账户会被拒绝启动 |
| `InpSessionStartHour` / `EndHour` | 8 / 21 | **服务器时间**，不是你的时间。先看 MT5 右下角的服务器时间对一下伦敦/纽约时段 |
| `InpFlatAllBeforeHour` | 22 | 该小时后强制清仓，短线不留隔夜 |
| `InpMaxSpreadUSD` | 0.35 | 按你经纪商的实际黄金点差调 |
| `InpAtrMinUSD` / `MaxUSD` | 0.8 / 8.0 | M5 ATR 区间，太静或太疯都不做 |
| `InpSlMaxUSD` | 6.0 | 但真正的上限是"风险金额 ÷ (最小手 × 100)"，小账户下由 `CalcLot` 兜底拒单 |
| `InpMinScore` | 5 | 7 分制。调到 6 会明显减少交易频率、提高质量 |

## 五、回测

MetaEditor → `视图` → `策略测试` → 选 `XAUUSD_ScalperGuard`：
- 品种 XAUUSD，周期 M5
- 模型选 **"每一笔分时"（Every tick based on real ticks）**，黄金对点差敏感，M1 OHLC 模型的结果不可信
- 初始入金填 200，杠杆填你实际的
- 至少跑 3–6 个月

**注意**：MT5 经济日历在策略测试器里不可用，回测时新闻过滤自动关闭 —— 所以回测结果会比实盘乐观（少了数据行情的挨打）。可以用 `InpManualNewsTimes` 手填时间窗口做粗略补偿。

## 六、运行要求

MT5 必须一直开着 EA 才会工作。关机 = 停止交易（已有持仓的止损还在经纪商服务器上，不会失效）。要 24 小时跑就得租一台 Forex VPS，或用经纪商送的 VPS。

---

## 七、从 Demo 转实盘之前

至少要有这些数据再谈：
- 连续跑满 **1 个月以上**、**30 笔以上**成交
- 日志里 `HALT` 记录看两件事：是靠 +$50 停的多，还是靠 -$15 停的多
- 最大回撤、连亏最长几笔
- 有多少笔是被"最小手数风险超限"拒掉的 —— 这个数字高说明账户规模和这套风控不匹配

真要上实盘，改 `InpAllowLiveAccount = true`。改之前请自己看一遍 `CalcLot()` 和 `OnTick()` 里的日内停止逻辑，确认你认同每一条。
